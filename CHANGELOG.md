## [0.1.0] - 2026-01-18

### Highlights

- Initial release of go-v2mom, a Go library and CLI for V2MOM strategic planning with OKR alignment

### Added

- Core V2MOM types: `V2MOM`, `Metadata`, `Value`, `Method`, `Measure`, `Obstacle`, `Project`
- Structure modes: flat (traditional V2MOM), nested (OKR-aligned), and hybrid
- Terminology support: v2mom (Methods/Measures/Obstacles), okr (Objectives/Key Results/Risks), hybrid
- Helper methods: `AllMeasures()`, `AllObstacles()`, `InferStructure()`, `GetStructure()`, `GetTerminology()`
- Validation with structure enforcement, `ValidationOptions`, and path-aware error reporting
- JSON Schema (Draft-07) for V2MOM documents with embedded schema via `//go:embed`
- Marp markdown renderer with theme support (default, corporate, minimal)
- Marp slides: title, vision, values, methods overview, obstacles, measures, progress dashboard
- CLI command `v2mom init` - generate template V2MOM JSON with `--name`, `--output`, `--structure` flags
- CLI command `v2mom validate` - validate V2MOM JSON with structure detection and error/warning reporting
- CLI command `v2mom generate marp` - generate Marp slides with `--output`, `--theme`, `--terminology` flags
- Example V2MOM documents: `product-v2mom.json`, `minimal-v2mom.json`, `agentplexus-v2mom.json`
- CI/CD workflows: multi-platform testing, golangci-lint, CodeQL security scanning
