## [v0.1.0] - 2026-01-18

### Highlights

- Initial release of go-v2mom, a Go library and CLI for V2MOM strategic planning with OKR alignment

### Added

- Core V2MOM types: `V2MOM`, `Metadata`, `Value`, `Method`, `Measure`, `Obstacle`, `Project` ([`f14907c`](https://github.com/grokify/go-v2mom/commit/f14907c))
- Structure modes: flat (traditional V2MOM), nested (OKR-aligned), and hybrid ([`f14907c`](https://github.com/grokify/go-v2mom/commit/f14907c))
- Terminology support: v2mom (Methods/Measures/Obstacles), okr (Objectives/Key Results/Risks), hybrid ([`f14907c`](https://github.com/grokify/go-v2mom/commit/f14907c))
- Helper methods: `AllMeasures()`, `AllObstacles()`, `InferStructure()`, `GetStructure()`, `GetTerminology()` ([`f14907c`](https://github.com/grokify/go-v2mom/commit/f14907c))
- Validation with structure enforcement, `ValidationOptions`, and path-aware error reporting ([`f14907c`](https://github.com/grokify/go-v2mom/commit/f14907c))
- JSON Schema (Draft-07) for V2MOM documents with embedded schema via `//go:embed` ([`ca6b3e7`](https://github.com/grokify/go-v2mom/commit/ca6b3e7))
- Marp markdown renderer with theme support (default, corporate, minimal) ([`46f9dd2`](https://github.com/grokify/go-v2mom/commit/46f9dd2))
- Marp slides: title, vision, values, methods overview, obstacles, measures, progress dashboard ([`46f9dd2`](https://github.com/grokify/go-v2mom/commit/46f9dd2))
- CLI command `v2mom init` - generate template V2MOM JSON with `--name`, `--output`, `--structure` flags ([`180f465`](https://github.com/grokify/go-v2mom/commit/180f465))
- CLI command `v2mom validate` - validate V2MOM JSON with structure detection and error/warning reporting ([`180f465`](https://github.com/grokify/go-v2mom/commit/180f465))
- CLI command `v2mom generate marp` - generate Marp slides with `--output`, `--theme`, `--terminology` flags ([`180f465`](https://github.com/grokify/go-v2mom/commit/180f465))
- Example V2MOM documents: `product-v2mom.json`, `minimal-v2mom.json`, `agentplexus-v2mom.json` ([`b2b0bb3`](https://github.com/grokify/go-v2mom/commit/b2b0bb3))
- CI/CD workflows: multi-platform testing, golangci-lint, CodeQL security scanning ([`f131380`](https://github.com/grokify/go-v2mom/commit/f131380))
